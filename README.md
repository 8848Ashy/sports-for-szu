# 深大预约助手 · sports-for-szu

Windows 本地桌面预约助手，支持羽毛球及一楼健身房。无需 AI API，也没有云端账号服务器。

**状态：0.1.0 试用版。离线测试已覆盖主要安全分支，未使用真实账号进行预约、扣款、取消验收。学校内部接口可能变化，不能保证抢到、支付成功或自动退款。请先小额人工验证，不要直接无人值守运行。**

这是独立编写的本地实现，并非 `Autur-wang/gym-bot` 的整包复制；没有附带任何个人 HAR 或账号配置。

## 功能

- 多个周计划：选择抢场星期、默认12:30、有效日期范围，以及预约当天/次日/几天后。按北京时间，不受电脑时区切换影响。
- 每个时段最多预约一场；多时段分别下单。周计划支持保存、修改、关闭、删除。
- 羽毛球场地优先级：默认 `B4-6,C4-6` 优先、`D7-8,A7-8` 靠后；中间是其他场地。靠后不等于禁止。
- 健身房独立预约类型与人数参数，不需要选择球场；资源标识从当次场地查询获取，不硬编码抓包中的 WID。
- 余额自动付款，单笔与每日上限。默认自动付款关闭；不保存支付密码，不充值。
- 每笔订单的“使用场地”与“取消”按钮。未确认默认在开始前60分钟取消，可设置更早；付款开关不会关闭取消规则。
- 在自动取消截止时间前约1小时发本机通知，默认即开场前约2小时。**没有手机远程推送**；Windows 通知设置可能影响提醒。
- SQLite 保存计划与订单；重启恢复托管，付款结果不明不重复扣款。
- 已结束且过了使用日的记录自动从当前列表隐藏，“显示历史”可查看。未核实异常记录不删，避免把失败藏起来。
- 可选记住登录密码：Windows DPAPI 加密保存，登录失效时有限次数尝试重新登录；验证码需本人完成。

## 安装与启动

需要 Windows 10/11、Python 3.11 或更新版本（安装时保留 tkinter 和 Python Launcher）。

1. 下载仓库 ZIP 并解压，或 `git clone` 到本地。
2. 双击 `setup.cmd`，安装独立 `.venv` 依赖及 Chromium。此过程不会登录学校账号。
3. 双击 `start.cmd`。
4. 在“账号与安全”填学号、姓名；可勾选记住密码。保存后点击“打开官方登录窗口”，完成学校登录与验证码。请始终使用配置的本人账号。
5. 新建预约计划，核对场馆准确名称、抢场星期与使用日。粤海羽毛球默认东馆；健身房默认运动广场西馆一楼健身房。其他场馆名称须与学校系统一致。
6. 启用计划，再点击“开启定时抢场”。只有两个开关都打开才下新订单。

```powershell
python -m unittest discover -s tests -v
.venv\Scripts\python.exe run.py
```

不同项目的放号规则可能不同：12:30是可修改的默认执行时间，不代表所有场馆均在此刻放号。

## 使用与安全说明

- 正常保持软件运行、电脑清醒且联网。关闭窗口收起到托盘；真正退出、睡眠或关机会停止工作。本版本不修改系统电源或启动设置。
- “暂停新预约”只暂停抢场，已有订单继续托管。“使用场地”只免除该订单的自动取消，不是入场签到，也不能代替付款。
- 最多补执行计划触发后的3分钟；超出窗口不补抢。没有场地时约每5秒查询，按优先级串行尝试，不大规模并发请求。
- 开始前不足“取消提前量+5分钟”时不再创建订单，避免刚付钱就到取消时间。
- 校园网站提示已支付订单需至少提前30分钟取消；本软件自动取消至少提前60分钟，错过安全窗口则告警并要求人工处理。以学校当前规则为准。
- 只管理本软件新创建并记录订单号的订单，不自动接管你已有的网页订单。
- 未支付订单超过创建后40分钟停止自动付款，避免接近网站45分钟期限时产生不确定结果。
- 余额不足、价格变化、超限、订单身份不匹配时不扣款。未知结果须官网核实，不通过自动重发“碰运气”。
- 密码与 Cookie 存放在 `%LOCALAPPDATA%\SportsForSZU\account.secret`，订单库在同目录。分享**代码仓库**即可，不要分享数据目录。
- 历史记录仅在界面归档，不立即物理删除：保留付款意图可防重复扣款。请勿删除尚有未结束订单的数据库。
- 原始 HAR 常含会话凭据，严禁提交。更多限制见 [SECURITY.md](SECURITY.md)。

## 上线前人工验收

自动化测试使用虚构账户与模拟服务器，不连接学校系统。首次启用真实自动付款前，请本人完成以下检查：

1. 登录后检查当前账号正确；先关闭自动付款，用一个时段验证返回场馆和订单一致。
2. 选一笔低金额、距离开场足够远的预约，核对余额支付后的订单支付状态与余额。
3. 分别验证“确认使用后不自动取消”和“未确认按截止时间取消”；核对退款结果，不只看HTTP状态。
4. 验证健身房、重启、登录过期、断网提醒；订单不明时到官网人工处理。

## 开发结构

- `models.py`：计划校验、北京时间、场地优先级、金额处理。
- `api.py`：固定学校域名的接口适配，无自动HTTP重试。
- `engine.py`：订单状态管理、付款/取消前落盘、周计划。
- `security.py`：DPAPI 凭据库与单实例锁。
- `store.py`：SQLite 持久化；`login.py`：官方浏览器登录。
- `ui.py`：本地桌面界面、托盘与本机提醒。

请遵守学校预约规则，勿用多人账号、大量并发或绕过认证的方式抢占资源。
