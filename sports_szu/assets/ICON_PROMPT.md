# 牛肉面图标

使用内置 image_gen，以用户提供的牛肉面照片为编辑输入；原照片未放入仓库。
最终提示词：

Use case: style-transfer. Edit target: supplied beef noodle photograph. Create a polished square Windows app icon, cartoon illustrated version of ONLY the main foreground bowl of beef noodles. Remove the upper background dishes, plate of egg food, table, background and spoon. Keep recognizable white bowl with navy blue triangular rim pattern, rich brown beef chunks, bright green bok choy, golden noodles visible in reddish broth. Simplify into bold rounded shapes readable at 32px, clean warm friendly cartoon with subtle dimension, centered three-quarter overhead view, entire bowl visible with generous transparent margin. Genuine transparent background. No text, letters, logos, watermark, extra dishes or UI. Output one single icon image.

noodles.png 为生成图，noodles.ico 为 Windows 多尺寸格式导出。
